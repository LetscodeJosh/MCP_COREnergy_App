# 🌐 PIMS MCP Web Simulator / Interactive Testing Environment

This directory contains the standalone Web Simulator for the PIMS MCP Application, providing browser testing and ERPNext API connectivity validation.

## 🚀 How to Run
Run the lightweight local PowerShell server:
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```
Then navigate to:
- **Local Browser:** `http://localhost:8080`
- **Mobile LAN Access:** `http://<your-lan-ip>:8080`
